Understanding Attention Mechanisms

2024-03-10 Paper Reading

Attention mechanisms have revolutionized natural language processing and are now fundamental to modern deep learning. In this post, I'll try to explain the key concepts behind attention and its theoretical properties.

What is Attention?

Attention allows models to dynamically focus on different parts of the input when producing output. Instead of compressing all information into a fixed-size representation, attention lets the model "attend to" relevant information.

Scaled Dot-Product Attention

The core computation in transformers is scaled dot-product attention:

Attention(Q, K, V) = softmax(QK^T / √d_k)V

where:

  • Q (Query) - what we're looking for
  • K (Key) - what we can offer
  • V (Value) - the actual information
  • d_k - dimension of keys (for scaling)

Why Scale by √d_k?

When d_k is large, the dot product grows large, pushing softmax into regions with extremely small gradients. The scaling by √d_k counteracts this effect.

Multi-Head Attention

Instead of using single attention heads, we use multiple heads in parallel:

MultiHead(Q, K, V) = Concat(head_1, ..., head_h)W^O

where head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)

Each head can learn different types of relationships:

  • Syntactic structure
  • Long-range dependencies
  • Contextual relationships

Theoretical Properties

Recent work has connected attention to classical machine learning concepts:

  • Attention vs. SVMs - Attention optimization dynamics can be viewed as SVM-like margin maximization
  • Representational Power - Transformers can simulate various computational paradigms
  • Sparsity - Attention naturally induces sparsity in attention patterns
